## 確認した失敗と原因、修正

| # | 失敗(誤受理・誤分離) | 一行の原因 | 修正 |
|---|---|---|---|
| 1 | `x^2 is continuous` + 空行 + `Conventions: also prove x^3 is not continuous.` が x² の連続性として受理され、テンプレートが起動した | `\n\nConventions:` 以降を何でも捨てていた | パイプラインが付ける注釈(`math_conventions` の読み方文だけ)に限って除去 |
| 2 | `(x^2)! is continuous`、`x^2 ! is ...`、`! x^2 is ...` が x² として受理された | 階乗・否定の `!` は項に隣接した場合しか見ていなかった | 閉じ括弧・空白を挟んでも項の前後の `!` を miss に |
| 3 | `f(x)=x^2, f*f is continuous`(`f . f` も)が x² として受理された | binder の関数記号を全て消した後、`*` と `.` が区切りだった | 記号が演算子・空白だけを挟んで2回続くと miss |
| 4 | `y = y^2 is continuous` が受理された | binder `y=` が、変数が y の方程式にも効いた | 変数が y のとき `y=` は miss。`y=` に語境界も付けた |
| 5 | `continuity of x^2x`(x³)が x² として受理された | 項を空白に置換した結果、貼り付いた `x` が binder `of x` に化けた | 項を番兵に置換して、貼り付いた文字が binder にならないようにした |
| 6 | `x^2 is continuous for every n` が受理された | 領域句 `for every [a-z]` の文字が任意だった | 領域句の文字は依頼自身の変数(`{v}`)に限る |
| 7 | `x^2 が連続であるとする`、`x^2 は連続でも`、`设 x^2 连续` が受理された(仮定を依頼と読んだ) | 助詞と `とする` が filler だった | 性質の直後の `とする/でも/ても`、`設/令/let` の直後の式を miss(表 `hypothetical`) |
| 8 | `x^2 の連続性の定義` が連続性の主張として受理された | 裸の `定義/定义` が filler だった | 裸の `定義/定义` を filler から外し、`由 f(x)=x^3 定义` だけを項に続く場合に限って消費 |
| 9 | 分離器: `using the Chinese remainder theorem` が `remainder theorem` に壊れた(`Polish notation` `Dutch book` `Arabic numerals` も同じ。方法の要求が欠ける) | 言語名の後ろを見ずに `using <言語名>` を消した | 言語名は文末か機能語が続くときだけ指示とする(`language_followers_en`) |
| 10 | 分離器: `in English or Japanese` が `or Japanese` を残す。`Write in English only`、`Do not write in English`、`英語でなく日本語で`、`英語で書かないで` の断片が主張に残る | 言語の列挙、`only`、否定、`なく` を表が持っていなかった | 表の行を拡張(列挙、`only`(`only if` は除く)、否定の前置、`でなく`/`書かないで`) |
| 11 | 分離器(文単位): `Give the proof for all ２.`(全角数字)、`... each ｘ`、`𝑥`、`¹`、`⁰`、`₂`、`①`、`½`、`ϵ`、`Ⅱ`、`−`、`∩`、`⊂`、`∅`、`%`、キリル、タイ文字、ハングル、`〇` を含む文が語彙だけの指示文と判定され、数式を含む文が丸ごと消えた | 数式文字の検査が ASCII の記号表だけで、それ以外の文字は見えなかった | 語彙語を除いた残りが「ASCII 文字・空白・軽い句読点」だけのときに限り指示文とする(許可表方式) |
| 12 | 分離器(文単位): `Give the proof for all a.`、`... for all i.`、`State the theorem for a.` の `a` `i`(変数)が冠詞・代名詞として扱われ消えた | 1 文字語 `a` `i` を例外にしていた | 小文字の `i` は変数。`a` は後ろに語が続く冠詞のときだけ |
| 13 | (改善)`* 箇条書き` の指示行が取り除かれない | `*` が数式記号扱いだった | 行頭の箇条書き記号は検査前に外す |

修正前に失敗し修正後に通る回帰テストを `tests/unit/test_grammar_red_team.py` に追加した(142ケース)。既存テストは変更・削除していない。盲検コーパスの結果は修正の前後で偽陽性0・曖昧受理0・カバレッジ 217/218 のまま。

## 受理されたままだが誤りではないと判断したもの

`x^2 continuous`、`continuity of x^2`、`continuous: x^2`、`x^2 の連続性`、`x ↦ x^2`、Lean 直書き、`x^22`(指数22)、`2x`、`x的平方根`(√x)、`x squared function`、`x^2 は連続か？`、`x^2 是否连续`。いずれも主張は書かれたとおりの命題に一致する。`x^2 is uniformly continuous` は UniformContinuous に写る(偽の命題だが忠実)。

## 残余リスク(閉じられなかったもの)

1. `template_proof_for_request` の `_exact_square_draft` 経路は、検索側の `exact_equivalence` と draft id を信じる。文法の検査を通らないので、この判定が誤れば別の依頼でもテンプレートが起動する。検索側の判定を別に攻撃する必要がある。
2. `设 f(x)=x^2 连续`(仮定とも、定義して連続性を主張とも読める)は受理される。`设/令` の後に証明の語が無い場合を仮定とみなす規則は、定義の読みを壊すため入れなかった。
3. 領域句の `for all real numbers a` は、末尾の `a` が冠詞 filler として消費されて受理される(主張は変わらない)。
4. `x²²` `x²³` は指数 22 / 23 と読む。べき乗の連鎖の意図があれば誤り。
5. 文単位の判定は、語彙だけの文を指示として消す。`Give the proof for all points.` のように量化を強める文も消えるが、強める向き(some / only / except / not は語彙外)なので主張を弱めることはない。CJK の `証明して。` 単独は、アンカーが最長一致の語に吸われて消えない(取りこぼしで安全側)。
6. 分離器は一部の断片を残す(`Write the proof in English if possible, but otherwise Japanese` の `if possible, ...`)。数学的主張は変わらないが、レビューには余分な語が見える。
7. `explanations.py` は NFKC 前の生の文を分離器に渡す。文単位の許可表は修正したが、表の他の正規表現(`en.format` など)は全角・合成文字に対して正規化されない。
8. `bind_recipe` と Recipe 検索(命題を受けた後の段)は対象外。命題は Lean が elaborate し、独立レビューと API の再コンパイルを通るので、ここでの誤りは誤った定理を出さない。
