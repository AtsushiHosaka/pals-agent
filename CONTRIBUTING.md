# Contributing

Thanks for your interest in `pals-agent`.

This project is still early. Keep contributions focused, small, and safe to
publish.

## Guidelines

- Do not include secrets or private infrastructure details.
- Keep public examples self-contained.
- Prefer interfaces and adapters over hard-coded PALS production dependencies.
- Run local checks before opening a pull request once the test suite exists.

## Public Boundary

If a change needs private API contracts, production deployment settings, or
internal prompts, it belongs in a private PALS repository rather than here.
