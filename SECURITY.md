# Security Policy

Do not report security issues in public issues.

For now, contact the repository owner privately through GitHub. A dedicated
security contact will be added before accepting outside production users.

## Sensitive Data

Do not commit API keys, database URLs, cloud credentials, Langfuse secrets,
private prompts, raw traces, or private datasets.

The repository ignores `.env.*`, `.claude/`, `.codex/`, logs, outputs, and local
artifacts by default.
